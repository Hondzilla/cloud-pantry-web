# Cloud Pantry Web Hub

Public static companion site for the Cloud Pantry Android household app.

## Deployment

This repository is designed for GitHub Pages through GitHub Actions.

Expected project URL:

`https://hondzilla.github.io/cloud-pantry-web/`

The Supabase publishable key is intentionally safe for public clients.
Never add a Supabase secret key or service-role key to this repository.

## Required GitHub setting

Repository → Settings → Pages → Source: **GitHub Actions**
